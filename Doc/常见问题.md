# 常见问题

## 1、openharmony C++模块 需要在模块级的 build-profile.json5 文件中添加对"armeabi-v7a"的支持（支持16位指令集）
### 问题现象：

在启动调试或运行C++应用/服务时，安装HAP出现错误，提示“error: install parse native so failed”错误信息，
或者运行时提示“TypeError：Cannot read property xxx of undefined”错误。

```
//build-profile.json5

// HarmonyOS工程
"buildOption": {
    "externalNativeOptions": {
        "abiFilters": ["arm64-v8a", "x86_64"]
    },
}
// OpenHarmony工程
"buildOption": {
    "externalNativeOptions": {
        "abiFilters": ["arm64-v8a", "x86_64", "armeabi-v7a"]
    },
}
```
